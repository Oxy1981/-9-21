Навіщо кав’ярні база даних?

У закладі «BubbleTea & Burgers» щодня сотні чеків, десятки напоїв і бургерів. В одному текстовому файлі чи гігантській таблиці ціни плутаються, дані дублюються, а виручку важко порахувати. Тому використовують бази даних.

Реляційна модель даних

База даних (БД) — упорядкована сукупність даних про певну предметну область (у нас — робота закладу).

Реляційна модель (від англ. relation — відношення) — дані подано у вигляді двовимірних пов’язаних таблиць.

  • Таблиця — однотипні об’єкти (Меню, Замовлення).
  • Поле (стовпець) — властивість об’єкта: Назва_позиції, Ціна_грн…
  • Запис (рядок) — один конкретний об’єкт.
  • Ключове поле (первинний ключ) — унікальне поле (часто лічильник ID), яке однозначно визначає запис і дозволяє зв’язувати таблиці без дублювання тексту.

СКБД (система керування базами даних) — програмне забезпечення для створення структури БД, додавання, оновлення, пошуку, видалення та захисту даних. Приклади: MS Access, SQLite, MySQL, PostgreSQL, навчальне середовище dat.A.

Веб-середовище dat.A

Онлайновий застосунок на основі SQL.js (рушій SQLite у браузері). Нічого не потрібно встановлювати.

  • Рядок меню: Файл, Створити, Дані, Таблиці, Запити, Звіти, Форми, Допомога.
  • Рядок заголовка: назва відкритої БД і логотип.
  • Робоча область: таблиці, запити, форми, звіти.
  • Спрощене меню: кнопка в куті екрана для смартфона чи планшета.

Де зберігаються дані

IndexedDB

Сховище самого браузера на цьому пристрої. Зміни зберігаються туди автоматично. На іншому комп’ютері або після очищення кешу й даних браузера бази не буде.

Файл .DTA

Власний формат dat.A: ZIP-архів з JSON-описом структури та двійковим дампом SQLite. Для резервної копії, перенесення на флешку чи Google Диск, надсилання вчителю.

Практична робота в dat.A

  1. Файл → Нова база даних (або Створити → База даних).
  2. Назва латиницею: BubbleTea_Burgers_Kovalenko (своє прізвище). Натисни Зберегти.
  3. Файл → Відомості: подивись ідентифікатор і розмір у байтах.
  4. Файл → Сховище: переконайся, що база є у списку IndexedDB.
  5. Файл → Зберегти як .DTA: файл з’явиться в «Завантаженнях».
  6. Файл → Закрити, потім Файл → Відкрити з .DTA — перевір відновлення.
